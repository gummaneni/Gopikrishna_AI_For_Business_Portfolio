## Reflection <br>
**What I learned across all modules:**<br>
This course took me through the full machine learning workflow, from framing a problem and exploring data to training, evaluating, and fine-tuning models. I started with a review of core ML concepts such as supervised vs. unsupervised learning, overfitting, and train/test splits. I then built on that with classification, Support Vector Machines, Decision Trees, dimensionality reduction, neural networks, and natural language processing. Each module showed me that there is no single "best" algorithm. The right choice depends on the data, the problem, and the trade-offs between accuracy, interpretability, and performance.<br>
**Skills I developed:**<br>
- Data preprocessing: cleaning data, handling missing values, scaling features, and encoding categorical variables<br>
- Model training and tuning: using cross-validation, grid search, and hyperparameter tuning to improve performance<br>
- Model evaluation: interpreting accuracy, precision, recall, F1-score, confusion matrices, and ROC curves<br>
- Dimensionality reduction: applying PCA to simplify data while keeping important information<br>
- Neural networks: building and training models with Keras/TensorFlow<br>
- Natural language processing: preparing text data and building models that work with language<br>
- Visualization: using Matplotlib and other tools to explore data and communicate results<br>
**How these projects prepare me for real-world ML tasks:**<br>
These projects gave me hands-on practice with the same steps used in industry: understanding a business problem, preparing messy data, choosing and comparing models, and explaining the results clearly. Working in Jupyter/Colab notebooks taught me to document my process so others can follow and reproduce my work. I now feel more confident approaching real-world problems such as customer classification, prediction, and text analysis, and choosing the right tools for each situation.<br>
## AI Statement<br>
I used Generative AI tools as a learning assistant throughout these projects. I used them to explain unfamiliar concepts, help debug error messages, suggest ways to improve or clean up my code, and check my understanding of model results. I did not use AI to replace my own work. I reviewed, tested, and modified every suggestion so I understood the code before including it in my notebooks. Using AI this way helped me learn faster and work more efficiently, and it taught me the importance of critically evaluating AI-generated output instead of accepting it without question. All final decisions, analysis, and conclusions in these projects are my own.<br>
